# My Open Source Journey & Technical Writing Portfolio

Hi, I’m Obaid.

This repository is where I’m documenting my open source journey and the way I think about documentation—what works, what doesn’t, and what I’m learning while I apply for programs like LFX.

I haven’t made contributions to these projects yet. The goal here is to show my understanding of the project problems, how I plan to approach them, and how I communicate technical work clearly.

---

## What’s inside

- **About:** Quick background and what I’m focusing on
- **Now:** A short weekly plan (what I’m reading, tracking, and attempting next)
- **Journey:** Where I started and what I’ve learned so far
- **Lessons:** What rejection/review feedback taught me
- **Case studies:** My understanding of the LFX project problems (Kyverno, Meshery, PipeCD)
- **Writing guide:** How I approach documenting real projects and how I avoid writing docs that waste time
- **Notes:** Raw outlines and research notes that I use while drafting
